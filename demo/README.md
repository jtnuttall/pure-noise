# Demo

A simple OpenGL demo app to demonstrate noise generated by `pure-noise`.

## Building

From this directory, inside the repo devshell (`nix develop` at the repo root
provides GHC, SDL2, GLEW, and the X11 headers dear-imgui needs):

```sh
cabal build demo
```

The `cabal.project` here builds against the in-repo `pure-noise` — not the
Hackage release — so the demo always shows the working tree's noise output.
